A headwear modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** adding a sleek, customizable motorcycle helmet accessory.

---

## 🎮 Features

- **Refined Alignment:** Slightly enlarged and shifted for a snug, natural fit over the head model.
- **Dual Color Palette Slots:** Independently customize both the **Helmet color** and **Visor tint/color**.
- **Shop Integration:** Available for purchase directly at the Clothier shop in-game.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.96.7`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/motorcycle-helmet/releases) page and download `Motorcycle_Helmet_Mod_v7-1.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Motorcycle_Helmet_Mod_v7-1.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Motorcycle Helmet/mod.json
   ```
4. Launch the game and visit the Clothier to purchase the helmet.
