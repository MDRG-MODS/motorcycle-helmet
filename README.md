A headwear modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** adding a sleek, customizable motorcycle helmet accessory.

---

## 🎮 Features

- **Refined Alignment:** Slightly enlarged and shifted for a snug, natural fit over the head model.
- **Dual Color Palette Slots:** Independently customize both the **Helmet color** and **Visor tint/color**.
- **Shop Integration:** Available for purchase directly at the Clothier shop in-game.
- Compatible with MDRG version **v0.97.12** (Target: `0.96.7`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/motorcycle-helmet/releases) tab.
